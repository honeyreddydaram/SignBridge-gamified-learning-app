# Screenshots

Real captures from the running app go here, named as below, then referenced
from the "Screenshots" section of the top-level `README.md`. Nothing in this
folder is generated or placeholder — only actual product screenshots.

| File | Capture |
|---|---|
| `01-dashboard-journey.png` | Dashboard / ASL Journey view — level, XP bar, streak, hearts, and the Alphabet → vocabulary-category progression map. |
| `02-recognition-live.png` | Recognition module mid-use — webcam feed with a live predicted letter shown. |
| `03-vocabulary-lesson-loop.png` | A vocabulary lesson mid-flow — either the video/description card (Learn) or the camera self-check step (Produce/Recall), clearly showing the self-check label. |
| `04-sign-quest.png` | A Sign Quest or scenario screen (e.g. the Greetings Quest checklist, or a scenario prompt). |
| `05-interpretation.png` | Interpretation — typed English text with the matching sign video playing back. |

Guidelines:
- PNG, browser window cropped to the app (no OS chrome needed).
- Use a real logged-in session with real progress where possible (e.g. some
  XP/streak already accrued for #1) rather than a fresh empty account.
- Keep width consistent where possible (~1280–1600px) for even rendering in
  the README.
